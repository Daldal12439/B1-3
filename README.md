# B1-3
노코드 자동화 기초: 워크플로우 설계
# 1. 미션 개요

## 주제

**행사 참석 여부 자동 확인 및 알림**

## 자동화 목적

행사 참석 여부를 매번 직접 확인하고 참가자에게 안내하는 반복 업무를 자동화한다.

Google Form으로 참석 여부를 접수하면 응답이 Google Sheets에 저장되고, 자동화 도구가 참석 여부를 확인하여 **참석 / 미참석**으로 조건을 분기한 뒤 이메일로 알림을 보낸다.

## 사용 도구

* Zapier
* Make
* Google Forms
* Google Sheets
* Email

---

# 2. 공통 워크플로우

두 자동화 도구에서 **동일한 구조**를 구현한다.

```text
Google Form
    ↓
Google Sheets
    ↓
새로운 응답 감지
    ↓
참석 여부 확인
   ↙        ↘
참석         미참석
 ↓             ↓
이메일        이메일
알림          알림
```

## 입력 데이터

Google Form에 다음 항목을 구성한다.

| 항목    | 내용       |
| ----- | -------- |
| 이름    | 응답자 이름   |
| 참석 여부 | 참석 / 미참석 |

Google Form이 제출되면 응답은 Google Sheets에 자동으로 저장된다.

---

# 3. 프로젝트 1 — 자동화 도구 비교 구현

## 3-1. Zapier 구현

### 워크플로우

```text
Google Sheets → 참석 여부 분기 → Email
```

### 구성

#### Trigger

**Google Sheets – New Spreadsheet Row**

Google Form의 새로운 응답이 Google Sheets에 추가되면 자동화를 시작한다.

#### 조건 분기

**Paths by Zapier**

* Path A: 참석
* Path B: 미참석

#### Action

* 참석 Path → **Email – Send Email**
* 미참석 Path → **Email – Send Email**

### 구현 과정

1. Google Form에서 이름과 참석 여부를 입력받도록 구성한다.
2. Google Form을 Google Sheets와 연결한다.
3. Zapier에서 Google Sheets의 **New Spreadsheet Row**를 Trigger로 설정한다.
4. 테스트 응답을 제출하여 Zapier가 응답 데이터를 정상적으로 가져오는지 확인한다.
5. Paths를 이용하여 참석과 미참석으로 조건을 분기한다.
6. 각 Path에 이메일 발송 Action을 추가한다.
7. 참석 및 미참석에 맞는 이메일 제목과 내용을 설정한다.
8. 실제 테스트를 통해 두 분기가 정상적으로 실행되는지 확인한다.

---

## 3-2. Make 구현

### 워크플로우

```text
Google Sheets → 참석 여부 분기 → Email
```

Zapier와 동일한 구조를 Make에서 구현한다.

### 구성

#### Trigger

**Google Sheets의 새로운 응답 감지**

#### 조건 분기

**Router**

* Route A: 참석
* Route B: 미참석

#### Action

* 참석 Route → **Email 발송**
* 미참석 Route → **Email 발송**

### 구현 과정

1. Google Sheets와 Make를 연결한다.
2. 새로운 응답을 감지하는 Trigger를 설정한다.
3. Router를 추가하여 참석 / 미참석 두 경로를 만든다.
4. 각 경로에 참석 여부 조건을 설정한다.
5. 각 경로에 이메일 발송 모듈을 추가한다.
6. 참석 응답과 미참석 응답을 각각 제출하여 두 경로의 실행을 확인한다.

# 4. 분기별 실행 결과

두 자동화 도구에서 각각 **참석과 미참석 응답을 최소 1회씩 테스트**한다.

| 테스트   | 입력                   | 예상 결과         | 결과 |
| ----- | -------------------- | ------------- | -- |
| ① 참석  | 이름: 홍길동 / 참석 여부: 참석  | 참석 안내 이메일 발송  | ✅  |
| ② 미참석 | 이름: 김철수 / 참석 여부: 미참석 | 미참석 안내 이메일 발송 | ✅  |

# 5. Make vs Zapier 비교 분석

| 비교 항목  | Make                                | Zapier                             |
| ------ | ----------------------------------- | ---------------------------------- |
| UI/UX  | 모듈을 캔버스에 배치하는 방식으로 전체 흐름을 한눈에 보기 쉬움 | 단계별로 설정하는 방식이라 처음 사용하는 사람도 접근하기 쉬움 |
| 설정 난이도 | 기능이 다양해 처음에는 다소 복잡하게 느껴질 수 있음       | 안내형 설정이 많아 비교적 직관적임                |
| 조건 분기  | Router를 사용하여 여러 경로를 시각적으로 구성하기 좋음   | Paths를 사용하여 조건별 경로를 구성할 수 있음       |
| 데이터 연결 | 모듈 사이의 데이터를 세부적으로 연결할 수 있음          | 이전 단계의 데이터를 선택하는 방식으로 비교적 간단함      |
| 실행 로그  | 실행 과정과 각 단계의 데이터를 확인하기 좋음           | Task History를 통해 실행 결과를 확인할 수 있음   |
| 연동 서비스 | 다양한 서비스와 모듈을 조합하여 복잡한 자동화 구성에 유리    | 다양한 서비스와 쉽게 연결할 수 있어 빠른 자동화에 유리    |
| 확장성    | 복잡한 조건이나 여러 단계의 자동화로 확장하기 좋음        | 간단한 자동화를 빠르게 확장하기 좋음               |

# 6. 장단점 비교

## Make

### 장점

* 전체 자동화 흐름을 시각적으로 확인하기 쉽다.
* Router를 이용한 조건 분기를 자유롭게 구성할 수 있다.
* 여러 단계의 복잡한 자동화로 확장하기 좋다.

### 단점

* 처음 사용할 경우 모듈과 데이터 연결 방식이 다소 어렵게 느껴질 수 있다.
* 간단한 자동화에서도 설정해야 할 항목이 많을 수 있다.

### 적합한 상황

조건 분기가 많거나 여러 단계의 작업을 연결해야 하는 **복잡한 자동화**에 적합하다.

---

## Zapier

### 장점

* 단계별 설정 방식이라 초보자가 사용하기 쉽다.
* Trigger와 Action의 구조를 이해하기 쉽다.
* 외부 서비스를 연결하는 과정이 비교적 간단하다.
* 간단한 자동화를 빠르게 구축할 수 있다.

### 단점

* 복잡한 자동화에서는 Make보다 시각적으로 흐름을 파악하기 어려울 수 있다.
* 무료 플랜에서는 작업량이나 일부 기능에 제한이 있을 수 있다.

### 적합한 상황

반복 업무를 처음 자동화하거나, 비교적 단순한 업무를 빠르게 자동화해야 하는 경우에 적합하다.

---

# 7. 비교 결과 및 선택 의견

이번 참석 여부 자동화에서는 **Zapier가 초보자가 사용하기에 더 편리하다**고 판단하였다.

Google Sheets를 Trigger로 설정하고, 참석 여부를 Paths로 분기한 뒤 이메일을 연결하는 과정이 단계별로 안내되어 있어 자동화의 기본 구조인 **Trigger → 조건 분기 → Action**을 이해하기 쉬웠다.

반면 Make는 전체 흐름을 시각적으로 확인하기 좋다는 장점이 있었다.

따라서 다음과 같이 판단하였다.

* **간단한 자동화 → Zapier**
* **복잡한 분기와 여러 단계의 자동화 → Make**

# 8. 프로젝트 2 — 자유 주제 자동화

## 주제

**행사 참석 여부 자동 확인 및 알림**

## 반복 업무 정의

행사 참가자의 참석 여부를 Google Form으로 접수한 뒤, 담당자가 응답을 확인하고 참석자와 미참석자를 구분하여 안내하는 작업을 자동화한다.

기존에는 담당자가 Google Sheets를 직접 확인해야 하지만, 자동화를 적용하면 새로운 응답이 등록되는 즉시 참석 여부를 확인하고 이메일을 보낼 수 있다.

## 선정 도구

**Zapier**

## 선정 이유

Zapier는 Google Sheets와 이메일을 쉽게 연결할 수 있고, **Trigger → 조건 분기 → Action**의 구조를 단계별로 구성할 수 있어 이번과 같은 단순한 반복 업무를 자동화하기에 적합하다고 판단하였다.

## 워크플로우

```text
① Google Form 제출
        ↓
② Google Sheets에 응답 저장
        ↓
③ 새로운 행 감지
        ↓
④ 참석 여부 확인
      ↙       ↘
   참석         미참석
    ↓             ↓
⑤ 이메일       ⑤ 이메일
   참석 알림      미참석 알림
```

## 자동 실행 과정

1. 사용자가 Google Form에 이름과 참석 여부를 입력한다.
2. Google Form의 응답이 Google Sheets에 자동으로 저장된다.
3. Zapier가 Google Sheets의 새로운 응답을 감지한다.
4. 참석 여부에 따라 두 개의 경로 중 하나를 선택한다.
5. 참석이면 참석 안내 이메일을 발송한다.
6. 미참석이면 미참석 안내 이메일을 발송한다.
